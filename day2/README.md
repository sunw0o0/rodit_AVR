# ADC 보고서
### 1. 왜 필요한가?

+ 끊어지지 않고 연속적인 값을 표현하는 아날로그 신호를 컴퓨터가 이해하는 디지털 신호로 바꿔주기 위해. (아트메가 속에 내장)
  + ex). 온도, 소리, 빛의 세기, 압력 등
 --------------------------
### 2. ADC의 핵심 동작

+ 표본화 (Sampling): 연속적인 아날로그 신호를 일정 시간 간격으로 콕콕 집어서 측정합니다.

+ 양자화 (Quantization): 측정된 연속적인 전압 값을 정해진 단계(레벨) 중 가장 가까운 정수 값으로 맞춥니다.

+ 부호화 (Encoding): 맞춘 정수 값을 0과 1로 이루어진 이진수로 바꿉니다.
 --------------------------
### 3. 해상도

+ 8비트 ADC: $2^8 = 256$단계로 쪼앰

+ 10비트 ADC: $2^{10} = 1024$단계로 쪼앰

+ 12비트 ADC: $2^{12} = 4096$단계로 쪼앰
 --------------------------
### 4. 잡음 제거

+ 아날로그 입력선을 최대한 짧게 한다

+ avcc에 연결할 떄는 LC필터를 거쳐 안정화 시킨다

+ ADC 동작중에는 병렬 I/O포트의 논리상태를 스위칭 하지 않는다(ADC가 전압을 측정할 때, 옆에서 노이즈가 튀면 값에 영향을 미칠 수 있)
 --------------------------
### 5. 레지스터

레지스터 == 기억장치.
MCU 칩 내부의 기능을 켜고 끄거나 상태를 확인하는 역할


+ ADMUX
  + 역할: 기준 전압(VREF) 선택 및 입력 채널(PF0~PF7 중 어떤 핀을 쓸지) 선택

+ ADCSRA
  + 역할: ADC 기능 활성화(ADEN), 변환 시작(ADSC), 분주비(Clock Prescaler) 설정, 인터럽트 허용 등
 
+ SFIOR
  + 역할: 트리거 모드(자동 연속 변환 등)를 사용할 때 설정하는 레지스터
