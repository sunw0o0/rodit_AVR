# I2C 통신의 SCL, SDA
+ 동기식 통신
    + 신호에 맞게 통신
+ 비동기식 통신
    + 일방적으로 통신. 따라서 시작비트와 종료비트가 필요함.

+ SCL
    + 역할: 통신 타이밍과 속도를 맞추기 위한 클럭(시간) 신호 전달
    + 클럭 신호선 - 마스터에서 슬레이브로 전송
  
+ SDA 
    + 역할: 마스터와 슬레이브(Slave) 사이에서 실제 데이터가 전송되는 선
    + 마스터와 슬리이브 간 데이버 송수

+ ATmega에서의 사용법
    + TWI(Two-Wire Interface) 하드웨어 모듈을 제어
    + (TWI = 두개의 선을 이용해 통신하는 방식) 
+ 동작 방식
    + 마슨터는 scl과 sda 핀이 모두 high일 때, sda를 low로 바꿔 슬레이브에게 통신 시작을 알림.
    + 마슨터는 우선 통신하고자 하는 슬레이브의 주소를 sda를 통해 송신
    + 해당 주소의 슬레이브와 통신
    + 마스터는 scl이 high이고 sda가 low인 상태에서 sda를 high로 바꿔 슬레이브에게 통신 종료를 알림
 
|--------| 마스터 | 슬레이브 |
|--------|--------|----------|
| 역할 | 지휘자 | 단원 |
| 주도권 | 통신 시작 가능 | 통신 시작 불가능 |
| 클록 (SCL) | 직접 생성 | 마스터의 클록에 맞춤 |
| 개수 | 주로 1개 | 여러개 |

# UART 통신
+ 시리얼통신
|-----| 직렬 통신 | 병렬 통신 |
|---|---|---|
| 사용 분야 | 외부 장치와의 통신 | 고속 전송이 필요한 내부 장치와의 통신 |
| 특징 | 1bit 씩 데이터 전송, 속도 느림, 장거리 데인터 전송 가능 | 속도 빠름 |

+ 232 통신(RS-232)
    + 데이터를 1bit 씩 전송하는 직렬 전송 방식
    + 통신을 하기 위한 최소단위는 1바이트(1bie = 8 bit) 이지만, 다른 데이터와 혼란을 방지하고자 앞뒤로 스타트 비트, 스톱 비트를 첨가
+ 485 통신(RS-485)
    +모든 슬레이브 디바이스들은 마스터 디바이스를 거티지 않고 다른 32개의 슬레이브 디바이스와 통신 가능
